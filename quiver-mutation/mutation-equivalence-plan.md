## 0. Problem and notation

Fix `n ≥ 3`. A quiver = skew-symmetric matrix `B ∈ Skew_n(ℤ)` (no loops/2-cycles by
convention). Mutation at `k`:

```
b'_ij = -b_ij                                   if i = k or j = k
b'_ij = b_ij + (|b_ik| b_kj + b_ik |b_kj|) / 2  otherwise
```

Each `μ_k` is a computable involution [LAB §1]. **MUT_n** is the decision problem:
given `B, B'`, are they connected by a mutation word? Open in general; the question
here is what a genuinely new attack looks like.

**Growth bound.** `|b'_ij| ≤ |b_ij| + M²` where `M = max |entries|`, so bit-length at
most roughly doubles per step: entries after `d` mutations are ≤ doubly exponential
in `d`. Mutation words are therefore verifiable certificates (exponential-time in
word length, but computable).

**Padding remark.** A zero row/column stays zero and its mutation is the identity, so
`B ↦ B ⊕ 0` gives MUT_n ≤ MUT_{n+1}. Hardness at any fixed rank is inherited upward.

## 1. Computability skeleton

**Prop 1.1.** MUT_n is Σ₁ (enumerate words). Hence:

> MUT_n is decidable ⟺ **in**equivalence is r.e. ⟺ there is a complete r.e. family
> of computable separating invariants.

The entire problem is the Π₁ side. Every known partial result fits this frame: solved
families are exactly those with a known complete invariant (§2) or a descent/normal
form (§3).

**Prop 1.2 (Dehn-function analog).** MUT_n is decidable ⟺ there is a computable
`D(B,B')` bounding mutation distance whenever `B ~ B'`. (⟸ search; ⟹ decidability
gives a computable distance by search.) So undecidability = *no computable
isoperimetric function for the mutation groupoid* — the correct analog of what
Novikov–Boone does to Dehn functions of group presentations.

**CEER framing.** For fixed `n`, mutation equivalence is a c.e. equivalence relation
generated by `n` computable involutions on a computable set — literally a CEER, and a
*naturally occurring* one (rare commodity; most CEERs in the hierarchy literature are
engineered). Question A: **where does Mut_n sit under computable reducibility `≤_c`?
Is it universal for some n?** Universality ⟹ undecidability and much more. I know of
no literature placing it ⚠️ (prior-art search needed: "mutation equivalence
decidable", recent arXiv).

## 2. The moduli meta-pattern

Every solved case found an ambient object of which quivers are shadows:

| family | complete invariant | mechanism |
|---|---|---|
| acyclic quivers | reflection class (source/sink moves) | cluster categories ⚠️ (Caldero–Keller?) |
| finite mutation type | surface + marked pts, or 1 of 11 exceptionals | Felikson–Shapiro–Tumarkin ⚠️ |
| surface quivers | topology of the triangulated surface | flips = mapping class groupoid |
| positroid/plabic quivers | decorated permutation | Postnikov boundary measurement ⚠️ |
| consistent dimer quivers (torus) | Newton polygon up to GL₂(ℤ) | Goncharov–Kenyon ⚠️ |
| rank 3 | Markov constant + descent tree | Vieta dynamics, BBH ⚠️ |

Nobody has ever solved a mutation class bare-handed. **Meta-thesis:** the general
problem is exactly "does a moduli always exist," and the plausible answer is no.

**Duality principle (the spine of the paper).** Every discovered invariant is an
*obstruction* the machine-builder must respect (it constrains where counters can
live); every machine gadget is a *counterexample template* the invariant-completeness
program must separate. Both programs converge on the same missing lemma — a
normal-form / no-merge theorem (§5.3) — and whichever side the lemma lands on decides
the problem. This is why building the lemma first is the right move even without
knowing the answer.

## 3. Rank 3: the anchor (dynamics fully visible)

Signed frame `(x,y,z) = (b_01, b_12, b_20)`; cyclic ⟺ all three same sign. On cyclic
weights, mutation is the Vieta move `(a,b,c) → (a, b, ab−c)` up to permutation.

**[LAB §3, §6] Chamber-structured invariants, empirically pinned:**
- signed `K = x²+y²+z²−xyz` is invariant on **acyclic→acyclic** mutations
  (7931/7931 random trials) and breaks at chamber crossings;
- weight-level `C = a²+b²+c²−abc` is invariant on **cyclic→cyclic** mutations
  (42529/42529).

So already the model case has *piecewise* invariant theory: polynomial invariants per
chamber-closed subfamily, walls where they hand off. This is the shape §4.2 automates.

**Descent.** Decidability of rank 3 rests on a Markov-tree-style *unique-parent
lemma*: off a finite minimal stratum, exactly one mutation strictly decreases the
weight, giving each level set of `C` a forest structure; equivalence = same tree.
(BBH classify mutation-cyclic rank 3 this way ⚠️ — exact statement to pull. Whether
full MUT₃ decidability is assembled *anywhere in writing* is worth checking; if not,
that's a warm-up section of the paper.)

**Arithmetic depth — and a sharp negative lesson.** Level sets of `C` are Markov-type
cubic surfaces `x²+y²+z²−xyz = m`; mutation classes within a level set are Vieta-group
orbits, i.e. this is the *class number* problem for these surfaces. Known/recalled ⚠️:
- Ghosh–Sarnak (Markoff-type cubic surfaces): class numbers > 1 occur; congruence
  obstructions exist; and there are (conjectured? proven?) **Hasse failures** — orbits
  not separated by any congruence invariant.
- Bourgain–Gamburd–Sarnak + W. Chen: Markov triples mod p are *connected* — mod-p
  invariants are blind within the main level set.

**Lesson 3.A.** If the Hasse-failure recollection holds up, then already at rank 3,
*finite congruence invariants are provably incomplete*, yet MUT₃ is decidable — via
descent, not invariants. So "find the complete invariant" is the wrong sole target;
descent/normal-form is the load-bearing structure, and §4's invariants are best
understood as the obstruction side of the duality principle.

## 4. Invariant machinery (three formal families)

### 4.1 Congruence invariants
Mutation is `B ↦ E B Eᵀ` with `E ∈ GL_n(ℤ)`, so for every `m`, the
`GL_n(ℤ/m)`-congruence class of `B mod m` is a mutation invariant — finite and
computable (orbit enumeration; canonical forms for efficiency). Subsumes det, Pfaffian
mod m, Smith normal form. [LAB §4]: `|Pf|` invariant 2000/2000 (with `Pf ↦ −Pf` each
mutation). [LAB §8]: mod-2 congruence does **not** obstruct the counter templates of
§5 — the ratchet failure is finer than congruence at m=2.

### 4.2 Chamber-wise polynomial invariants — automated
On each sign-chamber, `μ_k` is polynomial, so "`f` of degree ≤ d is invariant" is a
*linear* condition on `f`'s coefficients per chamber (identity on a full-dimensional
cone ⟹ identity of polynomials). Intersecting over `k` and chambers = finite linear
algebra per `(n, d)`. Rank 3 should mechanically recover the `K`/`C` chamber pieces;
**rank 4–5 is unexplored territory** and pure computation (Probe 1).

Same machinery, inequality version: search for **semi-invariants / Lyapunov
functions** `f(μ_k B) ≥ f(B)` on chamber-closed families, with positivity on cones
certified by Handelman/SOS — an LP. A global Lyapunov function with finite minimal
strata *is* a descent theorem, hence decidability for the family. Run as a CEGIS loop:
propose shape → mutation-search counterexample → refine. (This is what should
*explain* the [LAB §5/§7] ratchet failures — see §5.2.)

### 4.3 Finite abstractions and the profinite question
Abstract each entry to `(sign, value mod m, min(|value|, k))`. Exact mutation doesn't
descend, but a *nondeterministic* abstract mutation over-approximates (interval +
congruence arithmetic), so abstract non-reachability certifies genuine inequivalence —
abstract interpretation applied to mutation. Define `B ≈_fin B'` iff no finite
abstraction (nor congruence class, §4.1) separates them.

> **Completeness question.** Is `≈_fin` equal to mutation equivalence?
> Yes ⟹ MUT_n decidable (Prop 1.1). If §5 succeeds ⟹ provably no.
> And Lesson 3.A suggests it already fails at rank 3 within level sets —
> which would make "finite abstractions are incomplete for MUT₃" a clean,
> extractable theorem *independent of* the big question (Probe 3).

Boolean invariants worth folding in ⚠️: existence of reddening sequences is
mutation-invariant (Muller/Keller), while maximal-green-sequence existence is not
(Muller); finite vs infinite mutation type is decidable via FST.

## 5. The machine program (undecidability side)

> **RANK FLOOR (Danielle, 2026-07-04 — expert prior, ~1 year on rank 4).** Rank 4
> mutation equivalence is *decidable* ("easily solvable"). The machine program
> must therefore target **rank ≥ 5**. This retroactively explains every rank-4
> negative in this doc — the twin-hub freezing (§10), 0 ratchets across 174
> templates (§10.3), global invariants = exactly {1, Pf²} (§10.1) — as symptoms
> of a genuinely *tame* rank. Treat all rank-4 gadget work below as the
> **decidable-side illustration**, not a stepping stone to undecidability. The
> open structural question sharpens to: *what rank-4 structure fails to survive
> to rank 5?* The Pfaffian is the loud suspect — it is identically 0 at odd rank,
> so the entire degree-4 half of the twin-hub conservation law (its
> perfect-matching terms) has no rank-5 analog. The seam where a counter can live
> is exactly where that invariant evaporates.

Target: encode reachability of **reversible counter machines** (universal; Morita ⚠️)
into MUT_n for some fixed n. Counters = large entries; finite control = sign pattern +
small entries of a control block (finitely many states at fixed rank — finite control
comes for free). Reversibility is native: the groupoid is generated by involutions,
and equivalence is symmetric, so junk branches are harmless *provided they never merge
distinct machine configurations* (§5.3).

### 5.1 Primitive toolkit — verified [LAB §2]

With arm `b_ik = 1` and payload `b_kj = v`:

| primitive | behavior | status |
|---|---|---|
| P1 transvection | `μ_k`: `b_ij += v` when `v > 0`; arms flip (disarm) | [LAB] `+3→+8` for v=5 |
| P2 sign gate | `v < 0` ⟹ no-op (correction term vanishes on mixed signs) | [LAB] exact no-op |
| P3 reversibility | disarmed hub *subtracts* (involution seesaw) | [LAB] |
| P4 finite control | sign/small-entry pattern of control block | by design |
| P5 invariant placement | counter entries must be congruence- and Pfaffian-safe, e.g. rank-4 counter at `b_02` needs partner `b_13 = 0` since `Pf = b_01b_23 − b_02b_13 + b_03b_12` | forced by §4.1 |

P1+P2 is test-and-add — precisely Minsky material (zero test ⇝ sign test; equivalent
power with shifted counters). P5 is the duality principle in action: each known
invariant dictates gadget geometry.

### 5.2 The re-arming problem — current wall, with data

One increment is easy; *two* is the problem. After P1 fires, the hub is disarmed and
now decrements (P3). Re-arming by mutating an endpoint flips the accumulator column
too and pollutes neighbors (mutation updates all through-`k` pairs at once — the
coupled-update obstacle).

**[LAB §5, §7] Negative results.** Three rank-4 gadget families (twin unit hubs,
weight-2 arm, mixed-sign hubs; accumulator Pfaffian-safe): BFS over *all* mutation
words with intermediate entries ≤ 64 — the reachable small-entry islands are **finite**
(432 / 2429 / 3475 states) and contain **no** `c → c+1` or `c → c+2` ratchet.
**[LAB §8]** mod-2 congruence does *not* explain this (all `tmpl(c)` are mod-2
congruent). So either a finer invariant obstructs (Probe 1 should find it — a Lyapunov
on the gadget closure), or ratchets exist only through large-entry excursions, or
rank 4 with unit arms is genuinely too poor and the search must move to rank 5–6 /
non-unit arms (Probe 2).

The honest current state: **the seesaw is unbroken, and we don't know why.** That
"why" is exactly a semi-invariant question, i.e. the two halves of the duality
principle are already generating each other's next experiment.

### 5.3 The no-merge lemma (Britton analog)

Given encoded configurations `E ⊆ Q_n` with machine steps realized by mutation words
(forward simulation — milestone 1), the reduction needs: any mutation path between
points of `E` projects to a machine path. Sufficient structure: a potential `W` on
the mutation-closure with
1. machine words preserve the skeleton (level sets of `W`),
2. off-skeleton, every non-skeleton quiver has a **unique** strictly-`W`-descending
   mutation (unique parent ⟹ junk forms trees hanging off the skeleton ⟹ no merges).

This is *the same lemma shape* as rank-3 descent (§3). The irony is load-bearing: the
decidability program (descend to canonical forms) and the undecidability program
(control junk around machine skeletons) need the identical structural theorem, and
whichever family it's proven on tells you which theorem you got.

**Reframing (Danielle, 2026-07-04): the symmetric target ⟹ word problem, not
machine reachability.** Every mutation edge is traversable both ways (involutions),
so MUT is *undirected* reachability. The classical template for undecidable
undirected reachability is **Novikov–Boone word problems**, whose entire apparatus
(HNN extensions, Britton's lemma) exists precisely to forbid shortcut paths — i.e.
the "wrong mutations must not create shortcuts" problem is *exactly* what the group
theory was built to solve. Combined with the Garside locus (§6): relations live
only at `|b| ≤ 1` (involutions/squares/pentagons), so those sites are where
"relators" sit and `|b| ≥ 2` is free/rigid. So the natural rank-≥5 reduction may
be **a finitely-presented structure with undecidable word problem, realized via
small-entry relation sites** — more natural than a counter-with-reset. Reversible
(Morita) machines remain the source either way; reversibility is now *forced*.

**And ≈_fin becomes central at rank 5, not just rank 3.** Post-correction,
"ratchet-nonexistence ⟺ a separating invariant exists" is the *same* statement as
the ≈_fin completeness question (§4.3, C3) applied to the rank-5 family. So the
rank-3 C3 thread and the rank-5 freeze question are **one question at two ranks**:
does a complete family of computable invariants separate the classes? This unifies
two open threads and says the rank-5 gadgets' trivial invariant ring (§10.6) is a
data point *in the same series* as the rank-3 Markov-cubic class-number question.

### 5.4 Consequences of success at some rank n₀
- MUT_n undecidable for all `n ≥ n₀` (padding remark, §0).
- No computable mutation-distance bound (Prop 1.2) — non-computable "Dehn function".
- `≈_fin ≠ ~` (§4.3): explicit inequivalent pairs agreeing on all finite invariants.
- Mut_n lands high in the CEER hierarchy; universality plausibly follows from the
  standard uniformity of the encoding (Question A).

## 5.5 Descent = decidability (Danielle's rank-4 procedure) — the crisp fork

> **Danielle (2026-07-04): rank 4 is decided by "a fairly simple descent
> algorithm."** Not a complete invariant, not a geometric model — *descent*.

This snaps the whole program into focus and confirms Lesson 3.A (descent, not
invariants, is load-bearing) all the way up to rank 4. Restated crisply:

- **Decidability ⟺ computable normal form.** MUT_n is decidable iff mutation
  admits a computable descent to a canonical representative (the constructive
  form of the "computable Dehn function" of §1.2). Rank 3 (Markov/Vieta tree)
  and rank 4 (Danielle) both have it.
- **The unique-parent lemma of §5.3 IS the descent's termination+confluence
  condition.** A potential `Φ` with finite minimal stratum + a unique
  Φ-decreasing mutation off it ⟹ each class is a tree rooted at its normal form
  ⟹ compare roots. That is precisely "descent works."
- **So the duality principle sharpens to one coin:**
  `descent works ⟺ unique-parent holds ⟺ decidable`, and
  `machine encodable ⟺ descent is non-confluent / non-terminating ⟺ undecidable`.
  The machine program (§5) is *exactly* the construction of a rank-≥5 family
  where no descent can work: entries grow unboundedly (as in twin-hub) **but**
  the "downhill" move is not unique — two incomparable descents, or a
  reduction-cycle, encoding machine steps so that "do B, B′ share a normal form"
  becomes the halting/merge problem.
- **Reinterpreting the rank-4 evidence:** twin-hub *frozen* = descent working
  perfectly (each `tmpl(c)` is already its own normal form; distinct minima).
  Global invariants = {1, Pf²} and 0 ratchets/174 are what a descent-decidable
  rank looks like from the invariant/gadget side. All consistent.

**The rank-4 freeze, pinned algebraically [LAB].** Re-arming a fired hub by the
mutation *correction term* (add to an arm without a sign-flip) faces an
inconsistent sign system at rank 4. A single auxiliary vertex `v` trying to
restore both arms while preserving the accumulator `b_02` needs, simultaneously:
`b_0v,b_v2` opposite (keep `b_02`), `b_0v,b_v1` same (re-arm `b_01`), `b_1v,b_v2`
same (re-arm `b_12`) — chasing signs forces `b_1v` both positive and negative.
Contradiction ⟹ no single-vertex re-arm ⟹ the counter cannot tick ⟹ freezing.
(Verified: the near-miss gadget re-arms `b_01: −1→+1`, holds `b_02`, but drives
`b_12: −1→−3`.) *This is a candidate for the actual §5.2 obstruction the rank-4
descent exploits.*

**Concrete rank-5 target (Probe 5): SPLIT re-arm.** The contradiction dissolves
if two auxiliary vertices split the work — vertex 3 wired only to {0,1} re-arms
`b_01` (correction `+2`, and it touches neither `b_02` nor `b_12` since it misses
vertex 2); vertex 4 wired only to {1,2} re-arms `b_12` likewise. Neither vertex
faces the joint constraint, so each re-arm is individually consistent [both
half-gadgets hand-verified]. The open question is whether **the full cycle
closes**: firing the hub (`μ_1`) also perturbs `b_13,b_14`, and `μ_3,μ_4`
interact, so the search is for a short word `w` with `w·T(c) = π(T(c+1))`
uniformly in c, over the focused split-re-arm family (small tunable weights) —
not the blind {−1,0,1}⁴ sweep that gave only a cap-limited negative (§10.3). If
it closes, that single ratchet is the Minsky increment and the first crack in
descent-confluence at rank 5.

## 6. Groupoid presentation / Garside thread

For skew-symmetric `B`, a rank-2 subquiver has `|b_jk b_kj| = b² ∈ {0, 1, 4, 9, …}`,
so the *only* local relations among mutations are: involutions `μ_k²`, squares
(`b = 0`: commutation), pentagons (`b = ±1`); for `|b| ≥ 2` the rank-2 exchange graph
is infinite (locally free). Question: is `π₁(exchange graph)` generated by squares and
pentagons? (Known finite type — FZ; King–Qiu's cluster exchange groupoid is the
categorical version ⚠️; general case open.) On families with sparse pentagons this
smells like small cancellation ⟹ geodesic normal forms for *mutation words* ⟹ the
loop problem ("does word w fix B?") decidable — a stepping stone toward §5.3's control
of paths, independent of orbit questions.

## 10. Probe results (2026-07-03, second session)

Probes 1 and 2 were run. Code: `probe1_invariants.py` (exact mod-p invariant
search, two-prime confirmation, exact-integer anchors), `probe1b_extract.py`
(support-minimized extraction of separating invariants), `probe2_symbolic.py`
(symbolic-in-c island enumeration + self-similarity ratchet detector).

### 10.1 Probe 1 — invariant search [LAB]

**Calibration (rank 3) passed exactly as §4.2's theory predicts:**
- acyclic-restricted pure-polynomial search: kernel contains the signed Markov
  polynomial `K = b01² + b02² + b12² + b01·b02·b12` (verified exactly on 4000
  acyc→acyc pairs); kernel dim 5 — *more* invariants than expected (see 10.2).
- cyclic-restricted **pure**-polynomial search: kernel dim 1 (constants ONLY).
  This confirms the derivation that the weight Markov constant
  `C = sq − |prod|` is *not* a polynomial in the signed entries: on the cyclic
  cone the invariant is genuinely semi-algebraic. Chamber-wise invariant theory
  *needs* the signed-monomial basis.
- cyclic-restricted **signed**-feature search: recovers `C` (exact-verified,
  in kernel).

**Rank-4 global (degree ≤ 4, pure): kernel dim = exactly 2 = span{1, Pf²}.**
No other global polynomial invariant of degree ≤ 4 exists. Signed features at
degree ≤ 3 give constants only.

**Twin-hub class-restricted (3766 sampled mutation pairs, c ∈ 3..22), the
headline result — the seesaw has a conservation law:**

| basis | kernel dim | separates tmpl(5) vs tmpl(6)? | vs tmpl(7)? |
|---|---|---|---|
| pure polynomials, deg ≤ 6 | 211 | **NO** | **NO** |
| signed features, deg ≤ 4 | 123 | **YES** | **YES** |

(both confirmed at two primes, 2³¹−1 and 2147483629.) So: *no* polynomial
invariant up to degree 6 can witness the ratchet obstruction — consistent with
mod-2 congruence failing to — but a **sign-dependent chamber-wise invariant of
degree ≤ 4 separates consecutive counter values**. The obstruction blocking the
rank-4 counter gadgets is real, family-specific, and fundamentally
semi-algebraic. Extraction of its human-readable form: see 10.2/10.3.

### 10.2 Probe 1b — extraction

**The dim-5 acyclic rank-3 kernel, exactly (verified on 4000 pairs):**
`{1, b01², b02², b12², b01·b02·b12}` — each entry's square is *separately*
invariant on acyc→acyc mutations, plus the signed triple product. Explanation
(provable by hand from the sign structure): a rank-3 acyc→acyc single mutation
is always a sink/source move — any correction-firing mutation exits the acyclic
cone. So the acyclic chamber is dynamically rigid (reflection moves only), the
five invariants are the obvious ones, and the signed Markov `K` is their sum.
Nice corollary shape: "acyclic rank-3 mutation = reflection" falls out of the
invariant search automatically.

**Minimal separating degree on the twin-hub class = 4.** Signed-feature kernels
at degrees 1/2/3 have dims 1/2/14 and none separates tmpl(5) from tmpl(6);
degree 4 separates (10.1). The conservation law is degree-4, sign-dependent.

**The conservation law, extracted and exactly verified** (`probe1b_extract.py`,
46 signed-monomial terms, unique on its support — kernel dim 1 — zero violations
on all 3766 sampled twin-hub pairs, full formula in the probe output /
`probe1c_scope.py` parses it):

- degree ≤ 3 part: `−16·Σ_edges |b|²  −16·Σ_{4 faces of K₄} ε_face·2|b_ij b_ik b_jk|`
  where `ε_face = −1` if that triangle is cyclically oriented, `+1` if acyclic —
  i.e. **sign-gated Markov-constant terms, one per triangular face**, the gate
  being exactly the rank-3 cyclic/acyclic dichotomy;
- degree 4 part: matching-pair terms over the three perfect matchings of K₄
  (Pfaffian structure), sign-gated similarly.

Values: `f(tmpl(c)) = −16·((c+1)² + 3)` — strictly monotone in c, so it
separates **all** counter values pairwise: modulo extending sampled-invariance
to a proof on the whole class, *no mutation word connects tmpl(c) to tmpl(c′)
for any c ≠ c′* — the twin-hub family is frozen, each counter value its own
mutation class. This is the seesaw obstruction, explicitly.

**Scope [LAB `probe1c_scope.py`]: the invariant is NOT global** (7307/8000
violations on random rank-4 pairs) **and not shared by sibling families**
(~90% violations on mixed-sign-hub / arm-2 / perturbed-template orbit walks).
It is a conserved quantity of these particular mutation classes — the first
machine-discovered example of a family-specific invariant no global search would
find. (§10.4 corrects its *type*: it is orbit-conditional, **not** the
chamber-wise object §4.2 predicted — a stronger and subtler thing.) Two
consequences for the program:
1. (invariant side) rank-4 "Markov-analog" invariants exist per-class, built
   from face-orientation gates + matching terms — a template for a *general*
   structure theory of rank-4 class invariants (what function of the class
   determines the gates/coefficients?);
2. (machine side) counter gadgets at rank 4 must be designed to *break* this
   invariant's shape — or move to rank 5, where the sweep found no ratchet
   either but was cap-limited; the invariant-guided search (does an analogous
   conservation law exist for a candidate rank-5 family? if yes, skip it) is
   the right CEGIS pruner.

### 10.3 Probe 2 — symbolic ratchet sweep

Entries are polynomials in a symbolic counter `c`, signs taken for `c ≫ 0`, so
mutation is exact piecewise-polynomial and conclusions are uniform "for all
sufficiently large c". The **self-similarity detector** looks for *any* pair of

### 10.4 Probe 4 — twin-hub freezing PROVED (large c) + a correction

**Result [LAB `probe4_proof.py`]: the twin-hub family is frozen, proven, not
sampled** — for all sufficiently large c, `tmpl(c) ~ tmpl(c′) ⟺ c = c′`. Method:
along the orbit every entry is a polynomial in c, so `F(M) := f(M)` (large-c
sign resolution) is a polynomial in c; verified
- **C1** `F(M) = −16c²−32c−64` for all **49,296** states of the symbolic island
  up to degree 10 (exact, univariate in c);
- **C2** `F(μ_k M) = F(M)` on all **197,184** edges, *including* edges to
  over-degree-cap children (so pruning polynomials never drops an obligation);
- **C3** degree-monotone completeness: the `{deg ≤ 8}` slice (23,376 states) is
  *identical* enumerated at degree-cap 8 vs 10 — no low-degree state hides behind
  a high-degree detour, so `{deg ≤ D}` is inductively step-closed.

C1+C2+C3 + the standard Laurent degree-monotonicity ⟹ `F ≡ −16c²−32c−64` on the
whole (infinite) orbit; injective in c ⟹ frozen. **Threshold pinned [LAB]: the
sign-stabilization bound is `c ≥ 2`** — every island entry (to degree 8) already
carries its large-c sign for all c ≥ 2, so the proof applies verbatim there.
Residue is the two concrete cases `c ∈ {0, 1}` (template is meant for positive
counters regardless). So: **twin-hub frozen for all c ≥ 2, machine-proved.**

**Honest correction to §4.2 framing.** I'd filed `f` as a "chamber-wise
polynomial invariant" (the §4.2 automatable class). **It is not.** `f` is invariant
only *along the orbit*, not across the sign-chamber: random points inside the
seed chamber violate `f` **~99.6%** of the time (`probe4_chambers`/decisive test).
So `f` is an **orbit-conditional** invariant — it holds because the six entries
satisfy the specific algebraic relations of the twin-hub subvariety, not because
of a universal per-chamber identity. Consequences:
- the clean "finitely many chamber identities ⟹ invariance" proof route (which I
  attempted first) **provably fails here** — all 840 chamber-edge identities are
  non-trivial as formal polynomials. The working proof is the along-orbit
  induction above.
- §4.2's automated *chamber-wise* invariant search finds a strictly weaker class
  than what actually governs freezing. The real objects are **invariants of the
  Zariski closure of the orbit** (a mutation-closed subvariety). This is a more
  powerful — and harder — target than the plan first assumed, and it reframes the
  "structure theory of rank-4 class invariants" (§10.2 item 1) as: *describe the
  orbit subvariety and its coordinate-ring invariants*, not *fit a chamber
  polynomial*.
- reusable engine: `F ≡ target` on the symbolic island + degree-monotone closure
  is a general **freezing certificate** for any candidate family — exactly the
  CEGIS pruner §5/§10.3 wanted for the rank-5 hunt (does a candidate rank-5
  counter family admit such a certificate? if yes, it's frozen — skip it).

### 10.5 Probe 5 — rank 5 is LEAKY, not frozen (the key rank-5 finding)

The split-re-arm hypothesis (§5.5) was tested by symbolic-in-c island search +
step-by-step trace. Headline: **rank 5 is qualitatively unlike rank 4.**

- **Rank 4 = frozen** (counter cannot move at all; proven §10.4).
- **Rank 5 = leaky** [LAB trace]: the counter *does* move — firing the hub on a
  rank-5 split gadget takes `b02: 1000 → 1003` — but the gadget does not reset
  (a hub arm stays disarmed, and the auxiliary lines `b03, b04` grow). So the
  obstruction changed from "can't increment" to "increments but corrupts its own
  gadget." That is exactly the qualitative gap expected on the boundary between a
  descent-decidable rank and a machine-hosting one.

- **Leak mechanism, pinned [LAB]:** firing `μ_1` corrects the pairs `(0,3),(0,4)`
  via `(b_01,b_13)` and `(b_01,b_14)`; when those share the hub arm's sign the
  re-arm lines grow (`b03: 1→3`, `b04: 0→2`), and the growth leaks into `b02` on
  the subsequent re-arm mutations.
- **Fire-decoupling works** [LAB]: choosing `b_13, b_14` *opposite* to the hub
  arm makes `μ_1` leave `b03, b04` fixed and do `b02 += 1` *exactly*. But then
  after the flip `b_13 > 0`, the immediate re-arm `μ_3` sees `b_03, b_31`
  opposite-signed and fires no correction. **So fire-decoupling and re-arm demand
  opposite signs of `b_13`** — the rank-4 contradiction, now spread across the
  fire→re-arm *sequence* instead of a single vertex. A longer word (auxiliaries
  re-arming each other) is the candidate resolution; naive 3-step words cannot.

- **Searches (all completed):** focused split-re-arm family, symbolic-c island +
  self-similarity ratchet detector: **0 uniform ticks** in every configuration —
  (i) leaky seeds, DEGCAP 3, 64 seeds; (ii) fire-decoupled seeds, DEGCAP 4, 32
  seeds; (iii) **coupled auxiliaries** (`b34 ≠ 0`, so vertices 3,4 re-arm each
  other — the mechanism the sequencing analysis pointed to), DEGCAP 4, 32 seeds.
  These are **bounded** negatives, and the bound matters: a genuine tick can spike
  intermediate degree above the cap, the weight grids are small (|w| ≤ 2), and
  cycles longer than the degree-4 island's reach are invisible. So this is **not
  a rank-5 no-go** — it says the obvious "patch the rank-4 gadget" constructions
  don't close a *short, small-weight* cycle. Beating it needs one of: (a) much
  higher degree/weight budget (expensive search), (b) a genuinely different rank-5
  architecture (not a patched hub), or (c) a 6th vertex — which would make the
  undecidability floor n₀ = 6, still consistent with C1. **Live frontier; the
  next real step is a project on the scale of the rank-4 year, not a probe.**

2. **"Genuinely rank-5 + trivial polynomial invariant ring" is NOT sufficient for

3. **New sharp diagnostic (supersedes the invariant-ring test): descent-core

4. Matches Danielle's rank-4 "simple descent" and the Garside picture: finite core

is **provably infinite / cap-growing** — the computation lives in the core's
unbounded growth, not in a single counter entry.

**Correction (Danielle, asymmetry the "one coin" overstated):** finite core ⟹

the roots form a *recognizable* set with computable descent. So the sharpened
target is not "the core grows" but "**the core is not a decidable set**" (or:
descent depth is not computably bounded). A candidate family must have an
*unrecognizable / non-computably-bounded* descent core, not merely an infinite
one — a strictly stronger and more delicate condition.

### 10.17 The positive campaign = "finite forkless part" (an OPEN PROBLEM). Fork theory closes the loop.

Read the supplied papers in full. The positive campaign lands exactly on named,
active mathematics:

- **Warkentin forks** (Burcroff §2.3, ⚠️ Warkentin thesis): a *fork* is an abundant
  non-acyclic quiver with a **unique point of return** `r`; mutating at any of the
  other `n−1` vertices grows a larger fork (an `(n−1)`-ary tree of forks), while
  mutating at `r` moves *inward*. So the mutation graph of a mutation-infinite
  quiver = a (conjecturally finite) **forkless core** + infinite fork-trees hanging
  off it. **This IS the unique-parent structure of §5.3** — forks give a unique
  inward/descending direction; §5.3's "no-merge lemma" was Warkentin's fork theory
  all along.
- **Decidability ⟺ finite computable forkless part.** If a class's forkless part
  is finite, descend (toward points of return) to it and compare — decidable. The
  forkless part *is* the descent core my probes measure.
- **★ "Criterion for finite forkless part" is a STATED OPEN PROBLEM** (Burcroff,
  "Eventual Sign Coherence" 2605.12865, §"Finite Ice-Forkless Part": *"It is an
  interesting open problem to give a criterion for whether a mutation class has
  finite ice-forkless part"*). So my fork-horizon question to Danielle = this open
  problem. Known: verifiable case-by-case; preserved under freezing; **holds for
  infinite families** — COQ Ex 5.13 (2406.03604), Fomin/LMC Ex 10.1–10.2
  (2304.11505), and all mutation-acyclic (Neville, finitely many acyclic per
  Markov invariant). My Probe 16 (40/40 finite cores) = empirical evidence it is
  common/generic at rank 5.
- **Invariant hierarchy** (COQ 2406.03604): unipotent-companion integral
  congruence class ⟹ **Markov invariant** (generalizes BBH rank-3) ⟹ Casals'
  invariant ⟹ Seven–Ünal — all invariant under *proper* mutations. This is the
  arsenal that decides the mutation-acyclic/proper region (layer 1).
- **Burcroff's own result:** "eventual sign coherence" — almost every infinite
  mutation sequence eventually enters the fork region (probability 1) ⟹ the
  fork/tree structure dominates the mutation graph. Independent confirmation that
  the "wild" part is a thin core.
- Neville "Mysterious points in keys but not trees" (2603.17890) — cluster-variety
  *deep locus* geometry; tangential to MUT decidability.

**★ Positive-campaign target, precisely:** *give a criterion (or a large class)
